# Heavenlygiggles — Archive Rules

Use this file to keep the project clean without losing important knowledge.

## Keep Local
- `STATUS.md`, `CLIENT.md`, `DECISIONS.md`, `notebooklm.md`, `client_config.py` (if present)
- `brand-identity.md`, `brand-kit.json`, and `resources/`
- active code, tools, research in active use, and current deliverables

## Send To NotebookLM
- Updated `STATUS.md` at the end of every meaningful session
- `CLIENT.md` only when durable project context changes materially
- Major briefs, research summaries, and strategy documents worth preserving as long-term memory

## Send To Drive
- Client-facing deliverables
- Final exports, reports, and approval-ready artifacts
- Large source assets that should not clutter the local project root

## Keep In `.tmp`
- Session-generated sync bundles
- Temporary exports, scratch outputs, and transient logs
- Files that can be safely recreated

## Safe To Delete
- Duplicate scratch exports once preserved in Drive or a proper project folder
- Obvious temporary files left in `.tmp/`
- Generated cache/build artifacts when they are not the source of truth

## Rule Of Thumb
- NotebookLM = long-term memory
- Drive = client storage and deliverables
- Local project folder = working source of truth
- `.tmp/` = disposable workspace
